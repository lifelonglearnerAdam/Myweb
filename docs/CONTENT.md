课程材料用于确认实践范围：C / C++、数据结构、系统基础、数字逻辑、模式识别与综合课程设计。CS:APP 与 Stanford 学习材料被视为自学补充，不冒充 CMU / Stanford 的正式修课或学籍。

## 手记与文案

3 篇手记为本轮结合项目实现新整理的中英文草稿，不是从旧博客找回的历史文章。没有添加虚构的发布日期。本人在正式申请中使用时，应审阅第一人称表述、技术细节和观点是否与自身理解一致。
