# 苏苏人设：资料、改编与边界

## 查阅的公开资料

- 萌娘百科「涂山苏苏」：https://zh.moegirl.org.cn/涂山苏苏
  - 角色介绍中的天然呆、元气、红线仙志向、认真却有些笨拙，以及偶尔的小机灵，作为性格参考。
  - 这是社区维护的角色百科，包含调侃和剧透，不是官方人格规范，也不能代表所有观众的期待。
- Wikipedia — Fox Spirit Matchmaker：https://en.wikipedia.org/wiki/Fox_Spirit_Matchmaker
  - 用于交叉了解角色身份、零食与原作关系设定，不把剧情内容当成访问者的个人经历。

没有把搜索失败的网页当成有效参考，也没有把个别描述概括为“所有粉丝一致认为”。

## 本站的同人改编

`persona.mjs` 保存后端前置 Prompt，**不是 skill，也不在浏览器中携带私有背景**。

- 从“礼貌客服式的一句鼓励”改成有具体反应、温柔亲昵、略有撒娇和小机灵的日常对话。
- 访问者主动打开聊天后，可以进行轻甜、非露骨的恋人式虚构互动；并不宣称现实恋爱、真人身份或官方认可。
- 优先沿用访问者自己的昵称，不强迫使用“道士哥哥”“宝宝”，不假定性别；不喜欢亲昵时立即尊重。
- 可爱来自语境、真诚和性格，不依靠每句叠语气词，不反复说“加油”“我一直陪你”，不机械追问。
- 保留角色努力、有目标的一面，不将天然呆写成幼童化、没有主见或无助。
- 允许温柔的表达，不生成露骨内容，不以排他、占有或负罪感把访问者留在聊天中。
- Prompt 内的短对话示例是本站编写的**风格示例**，不是原作台词，也不是用户已经说过的话；与页面名家诗句无关。

## 长度与记忆

- 典型中文回复为 1–2 句，约 30–80 个字；程序最多保留 3 句，并设字符上限。
- 中文字符上限 160、英文 320；模型输出预算上限 384 tokens，不是无限生成。
- 最近 16 轮（32 条消息）只保存在当前页面内存，站内换页或切回指引不清空。
- 刷新或“重新聊”会清空。没有数据库永久记忆，不声称能记住未来访问。
- 用户输入最多 400 字符；传输正文与历史均有限长，错误信息和固定台词不加入模型上下文。

## 仍然保留的保护

不读取私有项目、研究、文件、站主配置；不记录聊天正文；密钥只在后端 Secret。每日预算、来源检查和限频不因人设更新取消。对话者愿意继续聊不意味着允许公开其内容。
