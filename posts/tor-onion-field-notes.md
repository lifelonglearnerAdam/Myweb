这篇文章整理自 2026 年 11 月 14 日的一次 AI 辅助配置与自动化浏览器验收。它是一份可复核的工程学习记录，不是新的匿名协议研究，也不是“绝对匿名”指南。原创概念插画由 IMAGE2.6 生成；线路、数字与真实页面证据分别标明。

# 先把地图展开：深网不是“另一个互联网”

![深网、暗网与公开网页的概念图：深网包含私人邮箱和登录系统；暗网只是特殊网络中的部分内容；示意不按规模比例绘制。](assets/images/posts/tor/web-layers.svg)

搜索引擎能索引的公开页面，只是我们习惯看到的入口。私人邮箱、登录后的云盘和内部数据库没有因此变得神秘，它们也属于通常所说的 **deep web**。

**dark web** 则强调借助特定软件或网络访问的服务。Tor 的 `.onion` 是一种例子，不是所有深网的统称。Tor Browser 同样可以访问普通 HTTPS 网站；一个 `.onion` 地址本身，也不能说明站点内容是否合法、可信或在线。

> 先理解“怎么到达”，再判断“到达了什么”。不要把网络工具等同于网络内容。

# 一条请求，要经过几双眼睛？

![普通 HTTPS 网站的典型 Tor 电路：浏览器经入口守卫、中继和出口到达网站。各节点掌握的信息不同，HTTPS 另在应用层保护传输内容。](assets/images/posts/tor/onion-routing.svg)

访问普通网站时，典型 Tor 电路包含入口守卫、中继和出口。客户端构造电路，把不同层的保护交给不同跳处理；通常单个中继不会同时掌握通信的真实来源与最终目标。

这不等于“没有人看见任何信息”。**直接连接入口时，入口知道连接来源；出口知道访问目标。** 如果目标网站没有 HTTPS，出口到网站之间的内容可能暴露。TLS 是浏览器与网站之间的另一层保护，不能由“用了 Tor”替代。

图里展示的是常规路径和局部可见性，不是对多点观察、时序关联或浏览器漏洞的安全证明。Tor 的目标是降低关联两端的能力，不是让通信从物理世界消失。

# 洋葱服务：不是把网站藏在出口后面

![概念插画：访问者与服务端各自穿过柔和的玻璃环，在中央会合。此图只表达会合的意象，不表示协议节点数量。](assets/images/posts/tor/rendezvous-art.webp)

![洋葱服务简化协议图：先通过服务描述符和介绍点建立联系，访问者与服务端各自建立电路，在会合点交换数据，不经过普通出口节点。](assets/images/posts/tor/onion-rendezvous.svg)

`.onion` 服务走的是另一条逻辑。客户端读取服务描述符，经介绍点传递会合信息；客户端和服务端再分别建立电路，在 **rendezvous point（会合点）** 连接起来。

介绍点与会合点不是同一个角色。会合点也不是普通出口：通信不需要先从 Tor 出口回到公网，再去寻找一台“隐藏服务器”。上图省略了密钥协商等细节，保留这两个阶段的区别。

所以，“让 Tor 出口也经过本机 VPN”不适合用来描述洋葱服务。这里根本没有普通网站访问中的那个出口。

# 把 Clash 放进去，到底改了哪一段？

![本次实验的连接链：浏览器保留本地 Tor 代理，本地 Tor 经受限转发连接 Clash，再经过加密代理节点进入 Tor；网站仍看到 Tor 出口。](assets/images/posts/tor/clash-chain.svg)

这次实验选择的顺序是：**浏览器 → 本地 Tor → Clash 的专用代理通道 → 远端代理节点 → Tor 网络**。对于普通网站，后面才接 Tor 出口与网站；对于洋葱服务，则进入前一镜的会合流程。

Clash 是代理和规则处理工具，本身不是一种 VPN 协议。仅仅把一个本机代理端口填进设置，不代表它一定选择了远端代理：规则模式里仍可能存在 `DIRECT`。本次为 Tor 单独建立不含直连选项的通道，不将浏览器的网页代理直接改成 Clash，避免绕过 Tor。

代价与信任也会移动：入口看到的连接来源可以变成代理节点，但代理服务方仍可能知道用户的连接来源。多加一层不自动等于更匿名，也不自动更快；这不是 Tor 官方面向所有人的通用推荐方案。[官方关于 Tor 与 VPN 的说明](https://support.torproject.org/tor-browser/general/vpn-with-tor/)也强调，需要先理解自己的威胁模型。

# 真正要紧的，是断线之后发生什么

![概念插画：一条细光线穿过玻璃桥上的门，旁边的门保持关闭。表达代理失效就停止，而不是寻找不安全捷径。](assets/images/posts/tor/gate-art.webp)

“连通时用了代理”和“失效时不会直连”，是两个不同问题。前者关注正常路径，后者关注 **fail closed：失败就停止**。

本次把这个启动方式下的浏览器和 Tor 放进仅有回环接口、没有外网路由的网络命名空间，只保留通往专用 Clash 通道的受限转发。直接 IPv4、IPv6 和 DNS/UDP 探测被拒绝，代理失效模拟没有回退直连。它是降低误配置风险的措施，不是抗入侵安全沙箱的完整证明。

边界也必须写清：其它应用、外部文档阅读器、不经这个启动方式打开的程序，不在这次隔离的覆盖范围内。配置变更与软件更新后也需要复查。不能从几项通过的探测，推导出“所有情形都绝不泄漏”。

> 如果安全要求是“不走这条路，就不要出发”，错误处理不能偷偷变成另一条路。

# 五个站点，五份证据，也有五种等待

![本次实际 Tor Browser 页面截图拼图：Riseup、Tor Metrics、Ahmia、Tor Project 与 SecureDrop 均显示正常正文并返回 HTTP 200。截图不是生成插画。](assets/images/posts/tor/five-sites-evidence.webp)

![五站首次验收耗时图：Riseup约13秒，Tor Metrics约17秒，Ahmia首页约28秒；Tor Project和SecureDrop首次超过45秒后续复测通过。复测缓存时间不能当作首次速度。](assets/images/posts/tor/observed-times.svg)

验收不是看见 SOCKS 握手就算成功。这五个不同的洋葱服务都在安装的 Tor Browser 中实际打开，核对了 **正文、页面状态、HTTP 200 与截图**。地址来自相应公开官网的页面或 `Onion-Location`，没有靠猜测同名镜像凑数。

记录中的首次验收约为：Riseup **13 秒**、Tor Metrics **17 秒**、Ahmia 首页 **28 秒**。Tor Project 与 SecureDrop 首次 45 秒超时，之后才显示正常页面。后两者热缓存复测的 **0.37 秒和 3.52 秒**，不能拿来与前面的首次打开做公平比较。

这只是一次环境中的单次观察，包含页面检查的时间，不是对 Tor 性能的统计基准，也不是站点持续在线承诺。代理测速的毫秒数、Tor 建路时间、网页完整渲染时间，更不是同一项指标。

还有失败：ZeroBin 公网首页能经 Tor 打开，但它自己公布的 v3 onion 地址返回 **服务描述符未找到**。Sci-Hub 仅验证了公网首页，没有检索或下载资料，不算洋葱站点通过。其它未能确认当前地址的名称，也没有被写成“已测试正常”。

# 两个搜索框，和一个不该被掩盖的问题

![两个搜索框的区别：地址栏默认引擎已经是Ahmia，但该版本Tor内置主页仍单独使用DuckDuckGo；另有Ahmia查询返回首页的未解决问题。](assets/images/posts/tor/two-search-boxes.svg)

“默认引擎已经改了，怎么还是 DuckDuckGo？”这个反馈是对的。该版本 Tor 内置欢迎页的搜索框有独立实现，不跟随地址栏的默认引擎。只检查配置文件，会漏掉实际看到的页面。

本次从运行中的浏览器内部确认：普通与隐私搜索引擎均为 **Ahmia**，主页改为 Ahmia，新标签页改为空白，避免继续出现那个独立的搜索框。界面与网页语言偏好统一为 **English (US)**，保留官方抗指纹设计，不把“自行堆很多扩展”误认为加强隐私。

但还剩一个真实问题：Ahmia 的测试查询与正常表单提交都回到了首页，未验证到正常的搜索结果。因此结论只能是 **引擎设置已生效，搜索功能未完全验收**。这个观察也不足以断定问题一定在本地配置或站点端。

> 能打开首页，不等于能用它搜索。失败记录也是研究结果的一部分。

# 片尾之前：匿名不是隐身

![隐私边界图：代理失效应该停止；隔离仅覆盖指定启动方式；真实身份登录、漏洞、恶意软件与流量关联仍需考虑，不能许诺绝对匿名。](assets/images/posts/tor/privacy-boundaries.svg)

这次最有价值的收获，不是一串“成功打开”的站名，而是把问题拆开：**谁看见哪一段、哪个程序受到约束、失败时有没有绕路、证据究竟支持到哪里**。

English (US) 与保留标准抗指纹配置，是减少与常见 Tor 用户差异的方向，不是单独的匿名保证。登录真实身份账号、混用浏览器、在外部程序打开下载文件、安装额外扩展，都可能改变暴露面。HTTPS、官方更新和清楚的使用边界，比“我已经套了很多层”更重要。

洋葱网络并不承诺即时抵达，也不承诺绝对不可识别。一个好的工程记录应当能同时写下两句话：**这里确实通过了；这里还没有证明。**
